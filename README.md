# Python Mini Project – Student Grade Calculator

## Module 2: Python Mini Project

This is a beginner-friendly Python project created for the internship.

### Features
- Takes marks for five subjects
- Validates marks from 0 to 100
- Calculates total marks
- Calculates percentage
- Assigns a grade
- Displays pass/fail status

### Concepts Used
- Variables
- Lists
- Loops
- Functions
- Conditional statements
- Input/output
- Exception handling

## How to Run

1. Install Python.
2. Open a terminal in this folder.
3. Run:

```bash
python student_grade_calculator.py
```
