# Module 2 Learning Notes – Python Mini Project

## Project: Student Grade Calculator

### Objective
The objective of this project is to apply basic Python programming concepts to build a simple practical application.

### Concepts Used
1. Variables – store marks and calculated results.
2. Lists – store marks of multiple subjects.
3. Loops – collect marks for each subject.
4. Functions – calculate the grade.
5. Conditional statements – assign grades based on percentage.
6. Exception handling – handle invalid user input.

### Project Workflow
Input marks → Validate marks → Calculate total → Calculate percentage → Assign grade → Display result.

### Learning Outcome
After completing this project, I understood how basic Python concepts can be combined to create a useful console-based application.
